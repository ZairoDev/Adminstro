# Glossary

## VSID

Vacation Saga / property identifier on the Properties model. Used to look up listings.

## Query

Primary traveller/guest lead document (phoneNo, leadStatus, location, etc.).

## Offer

Sales-offer / subscription pipeline lead document (phoneNumber, leadStatus, offerStatus, platform).

## Good-to-go

Lead board for leads ready for the next commercial step (`/dashboard/goodtogoleads`).

## exitedAt

On Candidate: set when the linked employee is separated; drives the People Exited tab.

## employeeCode

Permanent human-readable employee id (e.g. ZI-…) assigned at create time.

## Initiation limit

WhatsApp rule limiting how many new outbound conversations a role may start in a window.

## PIP

Performance Improvement Plan on the employee record; may require acknowledgment and can lock access when overdue.

## CRM Copilot

Internal assistant: RAG playbooks for how-to; read-only tools for live lookup; optional confirm-to-write proposals.
